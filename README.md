# Realm of Orlando — Portfolio RPG

Interactive portfolio built as a 2D RPG using Phaser.js + Vite.

## 🎮 Play it
[Live Demo](https://realmoforlando-portfolio-rpg.netlify.app/)

## ⚔️ Features
- Top-down exploration across multiple biomes
- Turn-based combat with boss phases
- Inventory system, dialog system, particle effects
- Full audio system across scenes

## 🛠️ Built with
- Phaser.js
- Vite
- JavaScript

## 🚀 Run locally
npm install
npm run dev
```
